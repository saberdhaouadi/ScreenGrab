# ScreenGrab
1. Android Studio (Ladybug or newer) > File > Open > select this folder.
2. Let Gradle sync (needs internet once, to download Gradle + libraries).
3. Plug in an Android 10+ phone (USB debugging on) and press Run.
   Or: Build > Build APK(s), then install app/build/outputs/apk/debug/app-debug.apk.
